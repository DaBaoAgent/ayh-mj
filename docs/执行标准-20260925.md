## 一、出片全流程（现行 7 步）

| 步骤 | 命令/操作 | 说明 |
|---|---|---|
| 1 组合选择 | `python tools/pick_combo.py`（`--commit` 记录） | 四池智能组合：角色组/卖点/角度/片型，保新优先 |
| 2 写 spec | 参照 **`tools/prep_w1_magic.py`**（最新样板） | 官方 Ref2VA 六段式 prompt（见 2.4） |

## 二、硬性规范（宝哥令·按最新）

### 2.1 影像与产品
- **折叠态必须竖立立在地面上**
- **展开态产品图：折叠 + 正侧 + 45 度三张一起给**（缺一不可）
- **复制人规避**：同框角色服装颜色强对比 + 硬约束 "only ONE xx man, never duplicated"
- **追/跟镜头只露背面**（脸永不出现）；跑动戏写"双人全程可见"
- 运镜要动；"从 X 脸上快速拉到全景"类开场可用

### 2.2 节奏（明快档）
- 开头静默 ≤0.15s｜结尾静默 ≤0.15s｜句间/换人/切镜停顿 ≥0.35s 一律压到 **0.20s**
- `tools/trim_onetake.py --apply` 自动执行；**不裁剪时不输出文件**（后处理须复制原片兜底）

### 2.3 台词
- **15s 档门禁口径：65-72 纯汉字**（`check_dialogue` 4.5-5.0 字/秒；**check 稿头部必须带 `duration="15"` 才会校验语速**，见 `tools/prep_s30_park.py`）（check_dialogue.mjs 口径 = 纯 CJK 字数）
- 每镜 2-3 句、镜内双人来回；单镜 ≤3 人；全片 2 人为主
- **禁破折号 "——"**（含破折号的整句会被 H3 丢弃，两次实测）
- 标点只用 `，。？！`；数字写中文（"三十九公里"）
- 字幕文本会经 ASS 层自动去标点（见 2.5）

### 2.3b 对白结构（宝哥 2026-09-26 令：**以后都按这种结构做**）
4 镜 8 句「双人对撞」模板（范本：`tools/prep_w3_lunyizu.py` + `docs/script-W3-轮椅组就您一个人-20260926.md`）

| 镜 | 谁 | 功能 | 宝哥口述定稿范例 |
|---|---|---|---|
| 1 | 她 | **人身羞辱**（当众、狠、纯口语） | 大爷，一把老骨头了，别来折腾了。 |
| 1 | 他 | 一句反击（短、带火气） | 切，你这是看不起我是吧。 |
| 2 | 她 | **当众下注**（赌注具体、**身体动作可演**） | 你赢我，我当场做一百个俯卧撑。 |
| 2 | 他 | 钉死（4-6 字） | 可别赖账啊。 |
| 3 | 她 | **体力崩溃求饶** | 我不行了，真不行了！ |
| 3 | 他 | 得意碾压（笑着补刀） | 这回服了吧？ |
| 4 | 她 | **当场兑现赌注（用画面演）+ 服气发问** | 你这到底什么车啊。 |
| 4 | 他 | **品牌句**（面向镜头，品牌名即收，不挂口号） | 爱优护轻便侠。 |

要点：
1. **赌注必须能演出来**（俯卧撑/鞠躬/下蹲）——结尾用动作兑现，比台词更爽
2. **品牌句极简**：只报品牌名，不追加卖点口号
3. **动作三件套**：她拍车座 → 他手背拨开；她指他胸口；她跟在车后伸手追；她当场做俯卧撑
4. 卖点靠**画面**承载（如调档动作），不靠台词讲解
5. 视线：对话看对方，仅品牌句看镜头（`lib/prompt_parts.GAZE`）

### 2.4 提示词（官方 Ref2VA 六段式 · 2026-09-25 起）
- **六段固定顺序**：`subject_definitions` → `summary` → `retention_analysis` → `detailed_description` → `overall_soundscape` → `non_diegetic_music`
- **音色-主体绑定显式声明**：`<Audio 1> is the voice-timbre reference for <Subject 1> (S1).`（降"说话人错配"）
- **切点格式**：`[Shot 2] At 00:04.000, the shot cuts to ...`（**Shot 1 不加时间戳**）
- **相机运动 = 类型+幅度+速度** 自然句（如 The camera pulls out with small amplitude at fast speed ...）
- 可见画面文字用英文双引号 + 原文
- 完整规范：`skills/media/autodl/references/prompt-writing.md`（含英文原文）

### 2.5 字幕（2026-09-25 最新）
- **字体：新青年体**（文悦新青年体 非商用 W8；fontsdir=`D:/@kaifa/fonts-douyin`）
- **不加粗**（ASS Style Bold=0）
- **不能有任何标点**（ASS 层 `_strip_punct` 自动清洗；中文数字转阿拉伯）
- 关键词黄字高亮 + 出场弹跳动效
- 底部位置：0.25 比例（=底边距 25.5%）

### 2.6 BGM 与音效
- **BGM 从 `assets/bgm_trending/`（36 首抖音热门）按剧情逐条分配、零重复**（分配表模板见 `docs/bgm分配-脑洞10连第二批-20260925.json`）
- `audio_polish.py --bgm "assets/bgm_trending/xx.mp3" --sfx --transcripts <json>`
- 音效 3 种：ding/whoosh/pop，按台词关键词自动插入

### 2.7 音色
- 真人样本库：`assets/cast/voice/real/`（42 个）+ 映射表 `docs/音色-角色映射表-20260925.md`
- **标准普通话样本优先**；口音样本只配"特色老外"角色
- **音色试听带**（宝哥要选音色时）：`tools/make_voice_audition.py` → 报号 + 候选样本拼成一条 MP3（统一 -16 LUFS 公平比对）
- 音色是**全片生成的输入**，必须先定稿再出片；定稿后改一行常量即可全片生效

### 2.8 说话人锁定（宝哥 2026-09-26 返工令 · **每镜必写**）
- 每镜点名「**只有谁说话**」，其余人嘴唇紧闭（`lib/prompt_parts.speaker_lock()`）
- **最强写法**：不说话的角色**直接不进这一镜**（"ONLY the girl is in this shot — no other person in the frame"）
- 说话人**必须面向听话人**（三分之四侧脸，不朝镜头）；店内多人场景 **只允许一个店员入画**
- 实测事故：①台词是主角的、画面里别人在动嘴 ②两个店员同时动嘴 —— 都是靠这条修掉的

### 2.9 使用者与产品铁律（宝哥 2026-09-26 令）
- **绝不写残疾人设定**（"cannot walk / 脚下无支撑"→ H3 会把**腿从画面里删掉**，实测 78s 处双腿消失）
- 改用 `lib/prompt_parts.RIDER_RULE`：普通健康人 + 自己操控 + **没人推**（不许有人碰靠背/推手）+ 双腿双脚**始终在画面内**踩脚踏板
- 产品形态保真：单台产品、每镜同一台、匹配参考图、不许变形/换车种

### 2.10 高风险镜头 5s 预筛（2026-09-26 固化，省"抽卡"钱）
- **成本账**：15s 正式片 ¥0.9 + 10-20 分钟；同内容 5s = ¥0.3 + 2-4 分钟
- 「没拍过的画面类型」（新道具细节、多人同框口型、特殊运镜、转盘指针类细节）**先快测再正式**
```bash
$PY tools/prescreen.py build state/onetake_prompt_job_<uid>.json --shot 3   # 抽第3镜 → 5s spec
$PY tools/prescreen.py run <uid>_shot3 --jobs 3                            # 提交下载
$PY tools/prescreen.py judge <uid>_shot3 --ask "转盘指针是否停在正上方那格？"  # 抽帧判读
```
- 判读不过就改提示词**再免费筛一轮**，别直接跑 15s（实测靠它拦下转盘指错格）

### 2.10b H3 prompt 硬上限 10000 字符（2026-09-26 X1 重跑实测 · 已代码级兜底）
- 服务端校验在**提交前**：超限则三个 fallback 工作流**全被拒、不扣费**，报错 `参数: prompt 的长度: N 大于最大长度 10000`
- 安全线 **≤9800**；`make_15s run` 预检与 `gen_one_take.py` 提交前**都已内置拦截**（超限直接中止并打印压缩指引）
- **压缩五招**（不删镜头、不改台词、约束强度不降；11506 → 9768 实测）：
  1. `pp.compose(cold_open=False)` 去掉全局 COLD OPEN 段（镜 1 描述里自带 extreme close-up）→ 省 ~280
  2. 每镜 SPEAKER LOCK 从「逐人长声明」（~400 字/镜）压成一句（~150 字/镜）＋ CAST 段加一条**全局 SPEAKER RULE**（~270 字）→ 净省 ~1000，语义等价
  3. 状态/动作类硬约束只写「几次、每次完整、不许空动」，动作细节留在各镜 desc → 省 ~540
  4. 每镜终态句压成一句（见 2.10c）→ 省 ~100
  5. `WHEEL` 段删括号解释、合并同意重复句 → 省 ~180
- ⚠️ `make_15s` 的 `do()` 曾用 `capture_output` 吞掉生成器报错（只显示「✗ H3 生成」）；现已改为**失败时打印生成器原始输出末 12 行**。手工排查时直接跑 `gen_one_take.py` 看原文最快

### 2.10c 形态变化类动作规格（折叠/展开/后躺；宝哥 2026-09-26 令）
适用：折叠、展开、145° 后躺等**静态形态变化**演示（H3 的强项，但写法有硬要求）。
- **必须演满三次完整形态变化**：`折叠→展开` / `展开→折叠` / `折叠→展开`——**不许写成「对已成形态的车反复按压」**
  （v1 事故原文 `presses the already-folded frame … does not collapse further or change shape` = 折叠态不动，宝哥判不合格重跑）
- 每镜**一次转换、一个动作人**（T14 定律：镜内事件 ≤3）；每镜写清**起始态 + 结束态**：
  `begins FOLDED, upright on the ground as a compact vertical column` → `UNFOLDS it in one single quick motion … ends FULLY OPEN, standing on all four wheels`
- **终态保持句必写**（否则 H3 在镜尾自己把车弹回原形态，5s 预筛实测）：
  `It ends folded/open and STAYS exactly like that for the rest of the shot — it never unfolds/folds back or changes shape again.`
- 全局加一条 `STATE-CHANGE RULE`：说明共几次、每次完整、**禁止「已成形态空按/空动」**、车轮始终着地
- 验收：**密抽帧**（0.5s 间隔 ≥10 帧）看过渡帧是否真的存在——8 格粗抽会把「特写首帧」误判成展开、把「有变化」判成「无变化」

### 2.11 验收口径（2026-09-26 三次踩坑后定）
- **抽帧点必须按「裁剪后」的时间轴算**：明快档后各段变短，沿用旧时间轴会抽到错镜（本次连错两次）；先累加各段 trim 后时长再定抽帧点
- **多条帧比"是否一致"要先拼成一张对比卡**（`frames_card.py --ts a,b,c`）——逐张发模型它无法比较
- **whisper 有时整段输出繁体** → 比对前必须繁转简（`lib/zh_norm.py`），否则一致率假低（实测把 1.000 算成 0.775）
- 台词复算（读缓存转写、不重跑 whisper）：`$PY tools/rescore_lines.py <uid>`
- **H3 持不住宽景**（只肯在宽景待 1-2 秒，且宽景常落在静音段被裁剪剪掉）→ 要「品牌句 + 产品全貌」就用
  `$PY tools/append_wide_tail.py --dir out/gen_job_<uid> --start 4.5 --dur 2.0` 剪成**结尾产品收尾镜**
- 生成中撞网络中断（Errno 10053 等）**别重提交**（重复扣钱）：`$PY tools/resume_task.py <task_id> <输出路径>` 接续下载
- 「短名 → 完整 uid」的映射**不得硬编码批次前缀**（写死会导致整段被静默跳过，实测踩过一次）

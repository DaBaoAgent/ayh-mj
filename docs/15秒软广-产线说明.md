# 15 秒软广产线（ayh-mj）· 使用说明

> 建立：2026-09-26 ｜ 入口：`tools/make_15s.py` ｜ 把 W2/W3/W4 手工跑通的链路固化为**一条命令**
> 结构规范：`docs/执行标准-20260925.md` §2.3b（4 镜 8 句对撞结构）｜ 范本成片：「48 轮椅组就您一个人」

## 一、最简用法

```bash
cd D:/@kaifa/ayh-mj && PY=.venv/Scripts/python.exe

# ① 造脚本（4 镜 8 句对撞结构模板）
$PY tools/make_15s.py new --uid W5_xxx --title "中文片名" \
    --lines 对白.txt --shots 分镜.txt \
    --cast-a 对手角色id --cast-b 车主角色id \
    --voice-a 对手音色.mp3 --voice-b 车主音色.mp3 \
    --desc-a "对手英文形象描述" --desc-b "车主英文形象描述" \
    --cast-note "a 20-year-old girl and a 70-year-old grandpa, both Chinese."

# ② 出片（生成 → 后期 → 验收 → 归档，一条到底）
$PY tools/make_15s.py run state/onetake_prompt_job_W5_xxx.json
```

**输入文件格式**
- `对白.txt`：**8 行**，每行一句；奇数行=对手（S1），偶数行=车主（S2）。镜 1=第 1-2 句、镜 2=第 3-4 句、镜 3=第 5-6 句、镜 4=第 7-8 句（第 8 句=品牌句，自动面向镜头）
- `分镜.txt`：**4 行**英文画面描述（每行 = 一镜的画面；含对抗动作/视线/逻辑链）

## 二、`run` 的 10 步（全自动）

| # | 步骤 | 说明 |
|---|---|---|
| 0 | 预检 | 台词 8 句 / 纯汉字 65-72 / 单句 ≤13 / 无阿拉伯数字（不过则拒跑，`--force` 强制） |
| 1 | H3 生成 | `minimax_h3_image_audio_to_video_v2_15s` 15s/768p（¥0.9，约 10 分钟） |
| 2 | 明快档裁剪 | 停顿 ≥0.35s → 0.2s（无静默可裁时兜底复制） |
| 3 | 转写 | faster-whisper small |
| 4 | 一致性自检 | 转写段数 vs 8 句 + 逐字一致率（自动打印，基线 75.4%） |
| 5 | 字级字幕 | 字符级对齐 + **孤行自动合并**（<0.35s 或 ≤2 字的行并进下一行） |
| 6 | 烧字幕 | 新青年体 / 无标点 / 关键词高亮 |
| 7 | BGM | `--bgm auto` 从 36 首热门库挑未用过的；也可 `--bgm 曲名.mp3` |
| 8 | 音效 4 点 | ding(第4句·赌约) / whoosh(第5句·力竭) / pop(第7句·兑现) / pop(第8句·品牌)，**素材自动归一化电平 + 限幅** |
| 9 | 抽帧验收卡 | 4 镜 × 2 帧 → `out/gen_<uid>/_frames_tmp/card.png` |
| 10 | 归档 + 桌面同步 | `rename_approved` 统一排号（用中文标题，幂等不重复）+ 桌面副本 |

**断点续传**：每步产物存在即跳过 → 中途失败重跑不重复花钱。
`--skip-gen`：已有 `onetake.mp4` 时只补后期。`--dry`：演练不花钱。

## 三、内置坑位（都被踩过，已在代码里处理）

| 坑 | 处理 |
|---|---|
| 门禁**不查字数**（prompt 无时长标记时 R10/R28 不触发） | `new`/`run` 都按**纯汉字 65-72** 自检并拦截 |
| 字幕把「一百」写成「100」 | 台词层强制中文读数；**音效定位**按数字串折算字数（1 串≈2 字），否则整条音效错位 |
| 字幕行数 ≠ 台词句数（8 句常被拆 10-12 行） | 音效点用**字数归并回 8 句**再取时间，**不能用行号索引**（实测错位 3 秒） |
| `audio_polish --sfx` 对无标点转写失效（规则靠「？！」匹配） | 产线自混音效，按句时间轴定位 |
| 音效素材电平仅 −25dB（怎么设系数都听不见） | 混音前 +17~26dB 归一化，混后 `alimiter=0.95` |
| 归档用拼音 uid → `rename_approved` 生成拼音条目/重复号 | 用 spec 的 `title`（中文）归档，幂等沿用原序号 |
| 精细接触动作被 H3 柔化（拍座/拨手→搭肩） | 脚本层改**大关节/大位移**动作；不强求则台词语义兜底 |

## 五、典型错误排查

| 症状 | 原因 | 处理 |
|---|---|---|
| `✗ 纯汉字 N 不在 65-72` | 对白太短 | 按自检提示补口语修饰字，重跑 `new` |
| `✗ 台词含阿拉伯数字` | 写了 100/39 | 改中文读数（一百/三十九） |
| 音效听起来错位 | 用了旧 SRT/行号索引 | 删 `out/gen_<uid>/onetake_trim.srt` 让产线重生成 |
| 归档出现重复号 | title 为空或改了片名 | 设 `--title`，或删掉错号文件后 `rename_approved` |
| H3 丢句/丢动作 | 一镜事件 >3 个 | 删动作或拆句（参考 `drama_craft_2026.md` 第 7 节） |

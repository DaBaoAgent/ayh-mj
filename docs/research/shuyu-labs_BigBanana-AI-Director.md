## 什么是 BigBanana AI Director

**BigBanana AI Director（中文名：大香蕉 AI 漫剧工场）** 是一个 **AI 一站式短剧／漫剧生成平台**，面向创作者，实现从灵感到成片的高效生产。

它摒弃了传统的「抽卡式」生成，采用 **"Script-to-Asset-to-Keyframe"** 的工业化工作流：通过深度集成 AntSK API 的先进 AI 模型，实现 **「一句话生成完整短剧，从剧本到成片全自动化」**，同时精准控制角色一致性、场景连续性与镜头运动。

### 一句话理解它解决的核心问题

AI 漫剧最致命的痛点不是画质、不是配音，而是**角色一致性**——换个镜头就变脸，观众瞬间出戏。BigBanana 正是冲着这个问题设计的：**先有演员和片场，再开机。**

## 它和其他 AI 漫剧工具的区别

| 对比维度 | 常见 AI 工具（可灵 / 即梦等生成类） | BigBanana AI Director |
|----------|--------------------------------------|------------------------|
| **定位** | 图像／视频生成核心，单图或单段产出 | 工业化全链路生产工作台 |
| **角色稳定性** | 多次生成容易变脸换人 | 定妆照 + 衣橱系统 + 上下文感知，三重约束锁定形象 |
| **工作方式** | 偏单张图／单段视频生成 | 剧本 → 资产 → 关键帧 → 成片一体化流程 |
| **视频控制** | 主要依赖文字描述，结果不稳定 | 首尾关键帧明确起止画面，中间由模型插值 |
| **场景延续性** | 难以保证连续性 | 场景概念图统一光影与风格，资产跨集复用 |
| **输出定位** | 更偏社交内容快速分享 | 可衔接 Premiere / Resolve 等专业后期流程 |
| **数据处理** | 常依赖云端上传 | 浏览器本地存储，隐私更稳 |
| **自动化程度** | 高（但可控性低） | 中高（需手动微调，可控性最高） |

> 一句话总结：**BigBanana 不是最自动化的 AI 漫剧工具，但它是目前最可控的方案之一。**

## 核心理念：关键帧驱动 (Keyframe-Driven)

传统的 Text-to-Video 往往难以控制具体的运镜和起止画面。BigBanana 引入了动画制作中的 **关键帧 (Keyframe)** 概念：

1. **先画后动**：先生成精准的起始帧 (Start) 和结束帧 (End)。
2. **插值生成**：利用 Veo 模型在两帧之间生成平滑的视频过渡。
3. **资产约束**：所有画面生成均受到「角色定妆照」和「场景概念图」的强约束，杜绝人物变形。

### 角色一致性的三重保障

这是 BigBanana 的核心竞争力，也是 AI 漫剧能否连载的关键：

| 机制 | 作用 |
|------|------|
| **第一重：定妆照系统** | 为每个角色生成标准参考图，作为全片视觉锚点，所有镜头生成都参考这张「脸」。 |
| **第二重：衣橱系统** | 同一角色可配置多套造型（日常装、战斗装、受伤状态），所有变体基于 Base Look 生成，保持面部特征不变。**换衣服不换人。** |
| **第三重：上下文感知生成** | 生成镜头时自动读取当前场景图、角色当前服装参考和道具参考。不是每个镜头从零开始，而是「知道」前面的剧情。 |

## 核心功能模块

### 项目级工作流 (Project Workspace)

* **项目中心 (Project Hub)**：集中管理最近项目、账号入口、模型配置、全局资产库，以及整库数据导入导出。
* **项目概览 (Project Overview)**：按「项目 → 季 → 集」组织内容，支持整篇小说导入并自动拆分多集草稿，也支持整项目备份导出。
* **项目资源与世界观 (Project Resources & Worldview)**：在单集制作前先沉淀角色 / 场景 / 道具资源，以及地图、区域、地点、音乐风格等世界观锚点，这些信息会持续注入后续剧情、资产和镜头生成。

### Phase 01: 叙事规划 (Narrative Planning)

* **结构化剧本生成**：输入故事大纲、小说片段或单集创意，AI 自动拆解出角色、场景、道具、镜头等结构化结果。
* **配置驱动生成**：可设置语言、目标时长、视觉风格和模型组合，统一控制后续全链路输出。
* **AI 续写与手动精修**：支持对剧本正文、角色视觉描述、镜头动作、台词和提示词进行续写、改写与逐项手动编辑。
* **全自动计划预审**：在正式批量生成前，系统会先给出全自动生产方案，允许你逐镜头决定使用「九宫格分镜」还是「首尾帧」链路。

### Phase 02: 一致性资产 (Consistency Assets)

* **角色一致性定妆**：为每个角色生成标准参考图，并通过衣橱系统维护多套造型的一致身份。
* **场景 / 道具资产化**：不仅生成核心场景图，也能为可复用道具建立独立提示词、参考图和形体参考。
* **资产库复用**：支持从项目资源或跨项目资产库选择角色、场景、道具，减少重复搭建。
* **批量补齐缺失资产**：可一键补齐角色、场景、道具的缺失图片，为后续镜头制作准备稳定上下文。

### Phase 03: 镜头制作 (Shot Workbench)

* **网格化镜头工作台**：全景式管理所有镜头，逐镜头查看叙事动作、角色、场景和道具上下文。
* **关键帧精控**：支持 Start Frame / End Frame 生成、上传、继承与编辑，增强镜头起止状态控制。
* **九宫格分镜预览**：可先生成 9 个候选视角，再选择整图或裁切单格作为首帧，快速确认构图方案。
* **上下文感知生成**：镜头生成时会自动读取当前场景图、角色服装参考和道具参考，显著降低「不连戏」。
* **双视频链路**：既支持单图 Image-to-Video，也支持首尾帧插值生成。

### Phase 04: 成片交付 (Delivery Center)

* **时间线预览与渲染追踪**：实时查看镜头完成度、粗剪时间线和渲染日志。
* **CutOS 风格 AI 粗剪**：内置时间线编辑器，可对已生成镜头做调序、裁剪、滤镜和导出前检查。
* **多种交付方式**：支持导出母版视频、片段压缩包和源素材，便于继续进入 Premiere / Resolve 等后期流程。
* **剧集级备份**：支持当前剧集数据导入导出，便于跨设备迁移与协作。

### Phase 05: 提示词管理 (Prompt Management)

* **集中检索与编辑**：统一查看模板、角色、场景、道具、关键帧和视频提示词。
* **版本回滚**：保留提示词编辑历史，可快速回退到旧版本。
* **跨阶段排查**：当结果不稳定时，可以直接回到这一页定位并修正上游提示词问题。

## 常见问题（FAQ）

### BigBanana 是免费的吗？有隐藏收费吗？

软件本身免费。Docker 镜像、桌面客户端和在线版均不收取软件授权费、订阅费或功能解锁费。**AI 模型调用费用由各供应商按实际用量收取**，你需要在各平台注册并配置 API Key。如需低成本体验，建议先用免费额度较多的模型（如 DeepSeek）。

### 为什么后续版本不再公开同步源码？

由于多次出现抄袭、不署名转载甚至恶意搬运，后续功能更新将只通过官方 Docker 镜像提供，不再同步公开源码。当前公开仓库保留为说明文档、`docker-compose.yaml` 与历史参考信息。**我们仍然针对商业版用户提供完整源码交付。**

> 这是一个被动的维护策略调整，并非放弃开源社区。完整的授权条款与商业合作方式见下方「许可证」章节。

### 生成的漫剧内容可以商用吗？版权归谁？

使用 BigBanana 创作的内容**版权归创作者所有**。但需注意两点：
1. 本项目代码采用 **CC BY-NC-SA 4.0** 协议，**商业使用需获取授权**（联系 antskpro@qq.com）。
2. 各 AI 模型供应商对生成内容的使用条款不同（如 OpenAI 允许商用、Google 有特定限制），商用前请查阅对应供应商的服务协议。

### 必须使用 AntSK API 吗？可以换成别的模型渠道吗？

公开版默认通过 AntSK API 统一接入，其优势是**跨模型兼容**（文本 / 图像 / 视频一站配置）与**价格优势**（低于官方渠道 80%）。如果你更倾向其他渠道，完全可以自行使用 OpenAI 或 Google 官方服务——这是正常且被尊重的选择。如需对接私有模型网关或深度定制，可基于商业版源码交付另行适配。

### 数据存在哪里？安全吗？

项目数据主要保存在**浏览器本地环境（IndexedDB）**，不依赖服务端存储。剧本、角色设定和生成画面优先留在本地设备内。这对正在孵化原创角色、尚未公开 IP 的创作者尤其重要——**你的角色资产，应该在你手里。**

> 需要注意：本地存储模式更适合个人创作与轻量协作，如需多人实时协作，请评估商业版方案。

### 新手能用吗？学习成本高吗？

BigBanana 是**工业化生产工具**，不是一键生成玩具。你不需要会画画、会剪辑，但需要具备一定的剧本意识，并愿意在分镜和台词上做轻量微调。如果你的诉求是「点一次按钮立刻全自动出爆款」，这款工具可能不适合你。

### 支持哪些操作系统？安装要求是什么？

支持 **Windows 10 及以上**和 **macOS 11 及以上**，基于 Electron 构建的桌面客户端。安装包约 122MB，安装即用，无需额外安装运行环境或依赖库。需要稳定的网络连接以调用 AI 模型 API。此外还提供**在线版**（浏览器直接使用）与 **Docker 部署**两种无需安装的方式。

### 默认画风是什么？可以改成写实风格吗？

默认画风为**动漫 / 插画风格**，适合漫剧和短篇动态漫画。你可以通过修改项目的「视觉风格」设置和各角色 / 场景的「视觉提示词」来调整画风方向，支持写实、赛博朋克、水彩、油画、像素风等多种风格。画风的最终呈现还与所选图像生成模型有关。

### 制作一集漫剧大概需要多长时间？

取决于篇幅和复杂度。以一个 **5 分钟、10 个镜头**的短篇漫剧为例，AI 导演团队通常需要 **1-2 小时**完成全部流程：剧本和角色设定约 20 分钟，分镜设计约 15 分钟，图像生成约 30 分钟，视频生成约 20 分钟，配音约 10 分钟。每个环节都支持人工审核和调整，熟练用户完成一集 5 分钟漫剧的实际耗时通常在 2-3 小时（含流程串联）。

## 快速开始

1. **完成账号 / 密钥配置**：首次进入时在新手引导、账号中心或模型配置中填入 AntSK API Key / Token。[**立即购买**](https://api.antsk.cn)
2. **创建项目**：在项目中心新建项目，后续所有季、集、资源和交付结果都会围绕该项目沉淀。
3. **搭建项目框架**：进入项目概览后，选择手动新建季 / 集，或直接导入整篇小说，让系统自动拆分多集草稿。
4. **补充项目资源**：按需先整理项目角色、场景、道具和世界观，让后续每一集都能复用统一设定。
5. **进入 Phase 01 叙事规划**：生成结构化剧本，并手动校对角色、动作、台词、提示词；如需批量生产，可先审阅「全自动模式」方案。
6. **进入 Phase 02 / 03**：先补齐一致性资产，再在镜头制作里生成首帧、尾帧、九宫格分镜和视频片段。
7. **进入 Phase 04 / 05**：在成片交付中预览、粗剪、导出与备份；若需要统一修正生成质量，再回到提示词管理集中调整。

```bash
# 浏览器打开 http://localhost:3005

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down
```

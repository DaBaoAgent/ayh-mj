# 迭代报告 v2 — 从"一镜到底"到"短剧级专业镜头"

> 2026-09-23 · 调研 4 个高星短剧/漫剧开源项目后的升级方案
> 触发：老板反馈「分镜/构图/运镜太不专业，要短剧漫剧类的专业水平」

## 一、调研结论（4 个高星项目）

| 项目 | ⭐ | 核心方法论（可移植） |
|---|---|---|
| **zenstory-ai/drama-skills** | 2,195 | 11技能全流程；**五份 Markdown 事实**（剧本/视觉设定/分镜/图片提示词/视频提示词）；**连续性锁**（跨镜造型短语锁）；**每镜含「目的/景别/机位/起点/终点/声音」**；剪辑单（入出点+取舍理由） |
| **shuyu-labs/BigBanana-AI-Director** | 2,260 | **Script-to-Asset-to-Keyframe**；「先有演员和片场，再开机」；**关键帧驱动**（先起帧/终帧→插值）；**九宫格构图预览**（9 候选视角选构图）；反对抽卡式 |
| **dramaclaw/dramaclaw** | 6,277 | **首帧先行**（five shot first frames → five shot videos）；Director World（3D 片场锁机位/空间一致性）；机位模板 + 镜头分析 |
| **chatfire-AI/huobao-drama** | 15,447 | 工程化平台（角色管理/视频任务/多模型）——工程架构参考 |

**四条共识**（所有项目一致）：
1. **多镜头快切**，不是一镜到底（样例：24 秒 = 21 镜分镜，单镜 5-8 秒）
2. **每镜设计镜头语言**：景别（特写/中景/近景/俯拍）+ 机位（过肩/侧背/固定）+ 运镜（推近/下压/跟随）
3. **资产先行**：定妆照锁定人物、场景板锁定空间（我们已有定妆图 ✅）
4. **声音有设计**：底噪 + 具体音效（茶缸落桌/滚轮停住/"静音半拍"）

## 二、问题诊断（我们 v1/v2 vs 专业）

| 维度 | 我们（当前） | 专业（drama-skills 样例） |
|---|---|---|
| 镜头结构 | ❌ 1 镜 15 秒一镜到底 | ✅ 4-8 镜快切，单镜 3-8 秒 |
| 镜头语言 | ❌ "Camera holds steady, no cuts" | ✅ "手背极近特写，固定机位" / "过肩近景" / "中景轻微推近" / "快速但稳定地下压" |
| 每镜目的 | ❌ 无 | ✅ "先用身体证据说明…" / "把发现时代红利的瞬间交给一个停住的手指" |
| 构图 | ❌ 单一 medium two-shot | ✅ 景别轮换：特写(手/物)→双人→近景(反应)→俯拍(桌面) |
| 起终点 | ❌ "对话流无重叠" | ✅ "起点：右手完全摊开；终点：纸角从画外滑来碰到指尖" |
| 声音设计 | ⚠️ 一段笼统 soundscape | ✅ "茶缸落桌一声轻响" / "滚轮声停住" / "绝对静音半拍" |

**v2 实测数据**（15秒单镜）也佐证缺陷：句与句之间有 1.4 秒空档、第5句被拆成两截——单镜长镜头无法做节奏控制。

## 三、迭代方案（三级升级）

### 升级 1：分镜结构（核心）— "15秒 = 4镜快切"

**重写 s3_storyboard/split.py**：每镜新字段

```json
{
  "seq": 1, "duration": 3,
  "purpose": "这一镜在叙事上干什么（必填）",
  "shot_size": "极近特写/近景/中景/全景",
  "camera": "机位+运镜（如：俯拍固定 / 过肩轻微推近）",
  "start_state": "起点画面",
  "end_state": "终点画面",
  "narration": "台词（≤时长×4.5字）",
  "sound_design": "对白+具体音效（如：金属松垮声/折叠咔哒声）",
  "product_ref": "产品图引用"
}
```

**镜头语言强制规则**（写进提示词）：
- 相邻镜头景别必须不同（特写→中景→近景轮换）
- 有产品/手部细节就用极近特写
- 反应镜头（情绪转折）用近景固定
- 每镜只有一个动作目标（起点→终点）

### 升级 2：生成链路 — "逐镜生成 + 无缝拼接"

```
旧：单次 15s 生成（v5_15s 工作流）→ 一镜到底
新：每镜独立生成（v5 工作流 1-10s）→ s5_compose 拼接
    ├─ 每镜参考图：定妆图 + 产品图（+ 场景图可选）
    ├─ 每镜独立提示词（专业镜头语言）
    └─ 拼接用现有 merge.py（TTS 对齐逻辑可复用，或保留 H3 原生对白）
```

**进阶（可选，二期）**：
- **首尾帧链路**：Seedream 先生成精确起帧/终帧（锁构图）→ H3 `minimax_h3_lightx2v` 首尾帧插值（动作可控）——BigBanana 核心做法
- **九宫格构图预览**：Seedream 生成 9 候选视角 → 人工/自动选构图——重点镜头用

### 升级 3：声音设计 — 每镜独立声场

- sound_design 字段写具体音效（不是"quiet ambience"这种笼统词）
- 保留 H3 原生对白/音效（已验证可行）
- 无背景音乐（维持）

## 四、新 15 秒分镜样板（「母子换车」专业版）

| 镜 | 时长 | 景别/机位 | 目的 | 起点→终点 | 声音 |
|---|---|---|---|---|---|
| 1 | 3s | **刹车部件极近特写·俯拍固定** | 3秒立住"旧车刹不住"危机 | 手指按磨损刹车片→拨动刹车线 | 底噪+金属松垮声（无对白） |
| 2 | 4s | **双人中景·儿子左前景侧背/母亲右后景** | 交代冲突 | 儿子蹲下指刹车→母亲扭头 | 对白两句+鸟鸣 |
| 3 | 4s | **折叠动作中近景·低角度仰拍轻微推近** | 轻量卖点可视化 | 单手提起折叠车架→滑进后备箱 | 对白+折叠咔哒声+滑入声 |
| 4 | 4s | **母亲面部近景·固定浅景深** | 情感落点（抗拒→松动） | 皱眉看后备箱→嘴角松动点头 | 对白+微风 |

对白分配（62字铺满 15 秒）：
- 镜2：儿子"妈，这车刹不住了，不能再骑。"（13字）+ 母亲"我用十年了，说扔就扔？"（11字）
- 镜3：儿子"这个才十三点八公斤，一只手拎得动。"（17字）
- 镜4：母亲"花那冤枉钱干嘛。"（8字）+ 儿子（画外）"你先试试，一键折叠，塞后备箱就走。"（15字）

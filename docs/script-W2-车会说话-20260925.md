## 七、审核可调项

1. **要不要加狗**：把邻居换成「遛狗阿姨」，狗先冲着车狂吠（**B12 遛狗互动**，萌宠流量）→ 但会变成 2 人 + 1 狗 + 1 车（6 图），H3 丢狗风险↑，建议先拍现版。
2. **误会款**：现版「藏人」→ 或「车里是不是有小偷」（更刺激，但可能触发平台敏感词）。
3. **大爷人设**：外国大爷（现）→ 或中国大爷 + 外国邻居（民族自豪感更强，但核心卡司组已用 3 次）。
4. **落镜动作**：邻居掏手机（现）→ 或只字幕收（更省镜头）。
5. **尾句金句**：爸妈一学就会（现）→ 「说一句，它就懂」（更贴合语音卖点，但略夸）。

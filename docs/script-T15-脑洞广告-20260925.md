# 脚本稿 · T15《相亲角·轻便侠相亲记》（脑洞广告）

> 状态：**待宝哥审核**（2026-09-25）
> 片型：**脑洞广告**——巧思设定+拟人化反转，笑点即卖点
> 核心创意：**给车"相亲"**——把产品功能翻译成"相亲条件"（**松手就停 = 老实不乱跑**）
> 主打卖点：**auto_stop 松手即停·电磁刹车**（卖点池首次使用）

## 一、一句话故事

公园相亲角，老王推着轻便侠来"给孩子找对象"——大妈问"给谁家孩子？"，老王：「**不给谁家，就给它。**」
大妈们先懵后进入状态，开始正经"相亲考核"："这孩子长得真精神！""它……老实不？"
老王淡定：「**松手就停，从不乱跑。**」——大妈拍手："这么好？！我闺女见了一定喜欢！"

## 板块 5 · 智能组合器

```bash
python tools/pick_combo.py                 # 全自动选四池组合（保新优先）
python tools/pick_combo.py --commit <uid>  # 选定并记录（防下条重复）
python tools/pick_combo.py --genre G4 --group 时尚组   # 指定某项
```
- 输出存 `state/combo_<时间戳>.json`
- 出片时按组合写脚本；模板仅在宝哥指定时使用（`AYH_USE_TEMPLATE=1`）

## 附 · 从"一键全流程/直接出片"到成片的路径

1. `pick_combo.py --commit <uid>` → 四池组合
2. 按组合（+角色组演员）写 7 句脚本（65-72字/明快档/快测模式写法）
3. prep（建 job + 参考图 6-7 张 + 音色 2-3 条）→ `check_dialogue.mjs` 0 ERROR
4. 480p×5s 快测 → 过 → 768p 正式
5. 明快档裁剪 → 字幕（≤10字/条）→ 归档 `out/approved/`

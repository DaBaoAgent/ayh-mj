## 一、一句话故事

小区停车坪，老邻居**老赵**（刚提新车、墨绿西装）张臂占住最后一个车位、当众小看**老王**的
轻便侠"塞不进缝"；老王反手立赌约 → **窄缝泊车**打脸 → 老赵嘴硬加码"你敢躺下？" →
段2 老王**拉杆放平靠背躺下**，老赵三顿饭认输。

**狗血引擎**：信息差马甲（观众知道车强、老赵不知道）＋ 赌约加码（车位 → 窄缝 → 三顿饭）
＋ 质疑者**亲自围观验证**（弯腰看靠背）＋ 身体动作兑现赌注（躺下）。

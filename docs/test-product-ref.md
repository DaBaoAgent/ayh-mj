# 产品保真诊断：为什么 H3 生成的轮椅"不像爱优护轻便侠"

> 触发：2026-09-24 宝哥反馈 T07 成片「轮椅不真实，不像我们的爱优护轻便侠，找到原因，测试一段 480 的 5 秒」
> 状态：对照测试进行中（A/B/C 三组 480p×5s）

## 一、现象

- T07 成片（v4）中，轮椅被判读为「普通手动轮椅」：无品牌字、无操控杆、电动特征缺失（抽帧 → vision 判读）
- T06 成片同类问题更轻（车有红弹簧点缀，品牌字被渲染成 "Air"）
- 宝哥观感：「不真实，不像我们的车」

## 二、真车标准（来自官方正侧图 `assets/products/正侧-3-无阴影.png`，vision 判读）

| 特征 | 内容 |
|---|---|
| 车架 | 深灰/哑光银灰金属质感 |
| 座椅/轮胎 | 黑色（靠背侧边有绿色线条点缀） |
| 轮子 | 四轮：前小万向后大，**后轮为轮毂电机（驱动轮）** |
| 红色部件 ×3 | ①前轮上方红色螺旋弹簧 ②座椅后方红色螺旋弹簧 ③后轮红色卡钳 |
| 品牌字 | 车架主支撑杆白色英文字母（Ainsnbot）+ 三角 A 形 Logo（折叠关节/轮毂中心） |
| 电动标志 | 左侧扶手前端黑色操控摇杆（带按钮+线束） |
| 其他 | 扶手人体工学、脚踏板可翻折、后轮手动推圈 |

## 三、疑点清单（带证据）

1. **【主因假设】产品参考图覆盖不足**：T07 只传了「折叠」单图（展开态无锚定）→ H3 脑补展开形态 → 脑补成通用轮椅
   - 证据：T06 用「折叠+正侧」双图（车好一档）；T07 为给 3 个角色腾位子砍了正侧图
2. **【次因】参考图被客户端缩到 ≤1280px**：`autodl_client.to_data_url` RESIZE_MAX_SIDE=1280，5000px 正侧图 → 1280px（细节损失大）
   - 反证：1280 版对 vision 仍可读（品牌字/红弹簧可辨）→ 严重性待测试评估
3. **【次因】场景复杂度稀释**：T07 是 3 人+狗同场（多条声轨+多主体），产品权重被稀释（vs T06 仅 2 人）
4. **【背景】H3 不是"像素复刻"，是"理解+再现"**：拿着产品图会画出它理解的"这类车"，细节服从度有限（品牌字历史问题：Ainsnbot→Air）

## 五、测试结果（2026-09-24 完成）

每条 5s/480p，抽帧 2.5s（展开中）与 4.5s（展示）→ vision 判读：

| 组 | 产品参考图 | 红弹簧 | 品牌字 | 电动特征 | 整体判读 |
|---|---|---|---|---|---|
| **A** | 折叠 单图（T07 现状） | ✓（前轮上方两组） | ❌ 无 | ❌ 无电机/控制面板/电池组 → 判"手动轮椅" | ❌ **"不像高档电动轮椅"** |
| **B** | 折叠 + 正侧 | ✓（前轮悬挂） | ✓（靠背+车架侧面） | ✓ 操纵杆+后轮电机轮毂+电池盒 → 判"电动" | ✓ **"像中高端便携式电动轮椅"** |
| **C** | 折叠 + 正侧 + 45度 | ✓（前轮附近两组） | ✓（车架侧面+靠背） | ✓ 轮毂电机样式、无手动推圈 → 判"电动" | ✓ **"像中高档轻便折叠型电动轮椅"** |

**决定性观察**：
1. A→B 一步之差 = 展开态参考图（正侧）：有它 → 品牌字/操纵杆/电机轮毂全出现；没它 → H3 脑补出通用手动轮椅
2. C 组额外读到**真车特有细节**：「靠背侧边绿色线条」（正侧图里的专属特征）→ 证明 H3 **确实在读取参考图细节**，参考图给什么它就还原什么
3. **480p 不是瓶颈**：B/C 在 480p 下就画出了品牌字+电动特征 → 此前 768p 出问题是**参考图问题**，不是分辨率问题
4. to_data_url 缩到 1280px 也非致命（B/C 用的就是 1280 版正侧图，效果依然好）
5. 提示词的红弹簧描述有效（A 组也有红弹簧）——但**电动感/品牌字只能靠参考图**

## 六、结论与修正方案

**根因（确认）**：**产品参考图覆盖不足**——T07 为给 3 个角色腾位子，砍掉了"展开态"正侧图，只留折叠单图；H3 展开态全靠脑补 → 脑补成通用轮椅。

**修正规范（已入技能）**：
1. **产品参考图必须 ≥2 张且含展开态**：最低配「折叠 + 正侧」，推荐「折叠 + 正侧 + 45度」（C 组效果最佳）
2. 参考图预算重新分配：上限实测可到 5 张（工作流支持 9）——角色多时用 5 图方案（3角色+2产品），不再牺牲产品图
3. 提示词保留红弹簧/品牌字描述（辅助），但主锚定靠参考图
4. 验收新增检查点：**成片判读"电动 or 手动"**（手动 = 不及格重跑）

## 一、这一批跟 W3/W4 有什么不同

W3/W4 是「羞辱 → 下注 → 崩溃 → 兑现」的短剧；这一批是**洗脑广告**：**同一句话砸三遍、同一个动作演三遍**，靠重复形成记忆点（对标 T14《魔性三连·超轻篇》的「十三点八公斤 ×2 + 单手提起 ×3」，本批升级为 **×3 + ×3**）。

| 结构位 | 谁 | 功能 | 本批写法 |
|---|---|---|---|
| 镜1 句1 | 她 | 质疑/低估（一句怼产品） | 每条不同角度：费劲 / 转不过来 / 刹不住 / 看不见 / 装不了 |
| 镜1 句2 | **他** | **记忆点句 第 1 遍** + 第一次演动作 | 短句 6-8 字，带数字或强节奏 |
| 镜2 句3 | 她 | 不信，**自己上手试** | 亲手折 / 亲手推 / 亲手摁 / 蹲下摸 |
| 镜2 句4 | **他** | **记忆点句 第 2 遍** | 只看她试，不解释 |
| 镜3 句5 | 她 | 当场被震到（表情夸张） | 瞪眼 / 眯眼 / 张口 |
| 镜3 句6 | **他** | **记忆点句 第 3 遍** + 第三次演动作 | 节奏收在最高点 |
| 镜4 句7 | 她 | 服气收尾（问价/要买/感叹） | 10 条各不同，不重样 |
| 镜4 句8 | **他** | **品牌句·面向镜头** | 只报品牌名「爱优护轻便侠。」 |

**两条硬口径**：① 记忆点**同一关键词讲 3 遍**（每遍换个引导词）；② 其余句子**不得复读**（提示词里写死：「记忆点是故意重复的 catchphrase，其余每句只念一次」）。

#### ⚠️ 为什么不逐字重复（门禁 R4 冲突，已解决）

`tools/check_dialogue.mjs` 的 **R4 规则**把「同一句台词出现多次」判为 **ERROR**（取每句前 12 字判重，本意是拦 H3 无意复读）——逐字 ×3 会被门禁直接拦死。所以洗脑点做成**同一关键词的三变体**：

`折它，就一秒钟的事。` → `你看，就一秒钟的事。` → `一秒钟的事，折好了。`

听感上仍是「同一句砸三遍」（重复的是记忆点短语本身，10 条关键词：一秒钟的事 / 指头 / 挪 / 尾灯 / 压 / 遥控 / 放 / 烫 / 行李箱 / 弹），但**门禁 0 ERROR**。

**若宝哥要真正的逐字 ×3**：给 R4 加 catchphrase 白名单（稿内声明 `<!-- catchphrase: … -->` 放行，约 5 分钟），代价是 H3 漏念/多念要转写复核——**您说一声我就改**。

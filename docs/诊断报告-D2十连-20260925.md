# D2 十连问题诊断报告（2026-09-25 · 宝哥逐条点名后全面排查）

> 宝哥报的问题：① 37「三箱货你还坐上去」该摊主说 ② 38「那你看着」该奶奶说 ③ 39 第4秒出现两个奶奶 + 后面很多对白说错 ④ 42 该奶奶全程坐在轮椅上而非推着 ⑤ 45 第4秒妈妈声音不对、第6秒女儿说话变成妈动嘴 ⑥ **所有字幕和对白都对不上**
> 结论：**6 类问题归为 2 类根因**——字幕对齐算法错误（可修，已修）+ 同片角色形象/音色过近导致 H3 混人（生成层，下批修）

## 一、根因 A：字幕与对白错位（可修，已修）

### 诊断方法
用 `faster-whisper` **逐字时间戳**把"字幕行"映射到实际语音位置，逐行算提前/滞后。

### 实测偏差（旧字幕）

**合计 31/87 行错位 ≥0.8s（36%）**，最严重 3.24 秒 —— 宝哥"都对不上"的判断被量化证实。

### 真根因
`s5_compose/burn_subtitles.py` 的 `burn()` **本来就支持** `expected_lines` 走 **DP 最优保序对齐**（`_try_align`：转写段与台词句做最小代价分组匹配，时间轴取真实转写段边界），但 **CLI 只暴露了 `--srt`**。
→ 批量脚本（B2 批、D2 批）只能用 `--srt`，各自实现「贪心分组 + 段内按字数比例切分」——**按字数比例猜时间就是错位之源**。

### 修法（已落地）
1. `burn_subtitles.py` CLI 新增 `--expected-file <txt>`（每行一句）→ 直进 DP 对齐路径。
2. `tools/post_batch_duikang10.py` 改为走该路径（不再自写 SRT）。
3. **只重烧字幕，不重跑视频**：清 `_trim_fx.mp4`/`_fx_polished.mp4` 后重跑 post（10 条已重烧）。

## 二、根因 B：同片角色形象/音色过近 → H3 混人（生成层，下批修）

### 证据链

| 现象 | 抽帧验证 |
|---|---|
| 37 台词串人 | 8.9-10.1s **白发爷爷持续动嘴**，而该句（三箱货，你还坐上去？）按脚本是**摊主**的词 |
| 39 复制人 | 4.0s/4.5s/5.0s/6.0s 画面里**两位穿紫衣、白发的相似老太太** |
| 42 推车 | 白发老太太**站在车旁用手推着轮椅**（脚本要求坐在座垫上驾驶） |
| 45 同脸 | 妈妈与女儿**被画成同一张脸**（"同一脸模，仅妆造不同"）→ 谁动嘴谁说话全乱 |

### 音色区分度（对 13 个音色样本算 f0 中位数）

**8/10 条是同性别角色对**，其中 6 条的 f0 差 <60Hz：

| 片 | 角色A | 角色B | f0 差 |
|---|---|---|---|
| 雨天尾灯 | 爷爷 137Hz | 邻居 101Hz | **36Hz** |
| 老年大学抢座 | 奶奶 154Hz | 老李 137Hz | **17Hz** |
| 夜市摞货 | 爷爷 137Hz | 摊主 177Hz | 40Hz |
| 旅游团大巴 | 爷爷 137Hz | 司机 177Hz | 40Hz |
| 茶楼踢轮 | 爷爷 137Hz | 老友 93Hz | 43Hz |
| 搬新家 | 爷爷 137Hz | 搬运工 190Hz | 54Hz |

**另一条**：`(S1)/(S2)` 编号本身对 H3 的约束力不足 —— 长交替对话（如 10 句里来回 5 轮）后容易串人。

### 修法（已写入 `tools/prep_duikang10.py`，下批生效）
1. **台词绑定带角色名**：`(S2) says:` → **`(S2) the stall owner says:`**（CAST_LIB 新增 `short` 字段）
2. **CAST 段硬约束**：两人必须明显不同（年龄/脸型/发色发型/服装色），**永不同脸、不同发、不似双胞胎**
3. **RIDING RULE**（防推车）：使用者**必须坐在座垫上**双手扶操纵杆行驶，**禁止推车/站旁边扶着走**
4. **选题规则**（定组合前先查）：优先**跨性别/跳年龄段**配对；同性别时必须视觉强对比 + **音色 f0 差 ≥60Hz**

**抽帧交叉验证**（字幕内容与字级时间表逐点比对）：
- #38 校门口急停：1.0s「大娘接孩子人多」/ 10.5s「松手就停稳稳当当」/ 13.8s「爱优护轻便侠」— 全对 ✅
- #41 搬新家：1.0s「你这小玩意儿能扛箱子」/ 6.5s「过门槛水一口没洒」/ 9.0s「汽车级的」/ 11.5s「下去你压不着」— 全对 ✅

原理：台词字符序列 ↔ 转写字符序列做**字符级**对齐，每句取首末字的真实时间；句内用 `_split_natural` 拆 ≤10 字自然行、按字数比例分配（句界准确 → 行界误差极小）。

**常见坑（已踩）**：拆行**不能硬切**（`clean[i:i+10]` 会把末字切孤行，如「…刹得住」+「吗」）——必须用 `_split_natural`。

**副带改善**：新路径用项目自带 `_explode_rows(max_chars=10)` 拆行 → 字幕每行 ≤10 字（旧路径是一句一行，品牌句 13 字超规范）。

### 执行方式（未重跑任何视频）
清 `_trim_fx.mp4` / `_fx_polished.mp4` → 跑 `post_batch_duikang10.py`（burn 走 `--expected-file` DP 对齐）→ 归档 → 改名。全程 **0 API 生成成本**。

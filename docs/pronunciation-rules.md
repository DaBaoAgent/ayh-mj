# H3 对白发音规则（爱优护视频）

> 2026-09-23 建立。来源：宝哥验收反馈（T01/T02/T04 咬字问题）+ 实测经验。
> 每次改台词/模板/提示词前对照本表检查。

## 一、数字读音

| 写法 | 读法 | 说明 |
|---|---|---|
| 218 | **二幺八** | 号码中的"一"读"幺"（yāo），不读"一" |
| 13.8 | 十三点八 | |
| 10 | 十（shí） | 发音清晰，语速快时防吞音 |
| 30° | 三十度 | 度字清晰 |

**实现方式**：直接写进台词文本（字符级最可靠）——H3 按字面朗读。

## 二、多音字表（易错）

| 字 | 语义 | 读法 | 例 |
|---|---|---|---|
| 重 | 重量义 | **zhòng** | 多重/多沉（H3 曾误读 chóng）|
| 行 | 行走 | xíng | 还行/推着走 |
| 行 | 行业 | háng | 这一行 |
| 还 | 仍然是 | hái | 还是这么顺 |
| 长 | 长度 | cháng | 多长 |
| 为 | 因为 | wèi | 因为 |

**策略（双保险）**：
1. **台词层避险**：易错词优先换无歧义词——"多重啊"→"有多沉啊"（已改 T04 模板）
2. **提示词注音**：无法替换时，读音标注写在 `<d>` 标签**外**（H3 只朗读 `<d>` 内文本）

## 三、品牌与型号

- **CTA 报品牌**："爱优护轻便侠"——**不报型号数字**（218）
- 历史问题：T02 收尾"二一八，就这么简单"读了"一"（yī）且报型号 → 模板已改"爱优护轻便侠，就这么简单"

## 四、语速与咬字

- 语速：**slightly brisk**（偏快一点点，不拖沓）
- 咬字：clear articulation；数字/关键词不吞音
- 实测：H3 默认为自然语速，提示词显式"a bit faster than natural"生效

## 五、字幕规则（显示层）

- 一行 ≤10 字（含标点计数，但输出时**不带标点**）
- 一次只显示一行；自然句成行（标点断句后去标点）
- ｜双人台词强制拆行
- 时间轴按字数比例分配
- 实现在 `s5_compose/burn_subtitles.py`（`_split_natural` / `_explode_rows`）

## 六、检查清单（每片必查）

- [ ] 台词无"多音字高危词"（重/行/还…）或已注音/替换
- [ ] 218→二幺八、13.8→十三点八
- [ ] CTA 报品牌不报型号
- [ ] 提示词语速标注 slightly brisk
- [ ] 字幕无标点、每行≤10字
- [ ] 转写回读核对（咬字错误会在转写里现形——如"十年"读错、"多chong"）

# 出片脚本规范 v2（2026-09-25 宝哥令：真实 / 爆点 / 停留）

> 本规范对**所有新 prep 生效**。写脚本时逐条自检。

## 一、前 3 秒钩子（必选其一）
每片**第一句台词/第一个画面**必须是以下三型之一：
1. **冲突喊话**：「婚礼马上开始了，快点！」「你疯了吧？」
2. **奇观动作**：产品做反常识动作（车自己动了 / 车被单手拎起）
3. **悬念提问**：「你猜我花多少钱买的？」

**禁**：平淡叙述开场（「今天天气不错」）。

## 二、0.5s 冲击开场（镜头规范）
- **镜头1 前 0.5 秒 = 大特写**（惊讶脸 / 指向的手 / 产品反光）
- 对白在 **0.25s 内**进入
- prompt 里已固化：`COLD_OPEN` 段（见 `lib/prompt_parts.py`）

## 三、反转 ×2（结构规范）
- **反转1（前 5s）**：钩子反转（预期被打破，如「以为学不会」→「车听懂了」）
- **反转2（中后段）**：打脸/神转折（如「这伴郎没白请」「说走就走」）
- 两反转之间保持信息推进，不注水

## 四、光线质感词（prompt 规范）
所有 prompt 拼入 `REALISM` 段（纪实摄影 / 自然光 / 皮肤纹理 / 85mm f/2 / 无塑料感）
→ 统一走 `lib/prompt_parts.compose()`

## 五、声音规范
- **音色**：优先真人样本（`assets/cast/voice/real/`，映射见音色-角色映射表）
- **BGM**：后期铺底（宝哥免费音乐库，25-30% 音量）——`tools/audio_polish.py --bgm`
- **音效**：动作/惊讶点 3-5 个（`--sfx`，自动对台词时间轴）

## 六、字幕规范
- 关键词高亮（黄/红 + 130% 放大）——`burn_subtitles.py` 自动处理
- 结尾 CTA 字幕：「你家老人用得上吗？」类提问（引导评论）

## 七、台词规范（沿用）
- 65-72 字 / 7-8 句 / 每句只念一遍 / 说话人脸朝镜头 / 镜头 4 个（一镜多句）
- check_dialogue.mjs 必须 0 ERROR

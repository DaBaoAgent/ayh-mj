## 二、核心打法提炼（三批各自总结）

### A 组（打脸逆袭）——3 条铁律
1. **羞辱场景 + 隐藏身份 + 分层揭晓**：「什么时候亮底牌」比「是什么身份」更重要——先护短 → 再撑场 → 最后在最不起眼的场景亮王牌
2. **打脸对象要「具体的一句话」**：爽点的记忆点 = **一句原话 + 一个动作**（「叫你倒反天罡」+砸花束；「没本事、父母是穷鬼」+父母现身）。热度再高但只查到简介级描述的剧，学不到写法
3. **★「体面爽」正对中老年受众**（2026 最新趋势）：红果 45 岁以上用户过半；《好雨知时节》「摊开证据、体面拆婚」30 亿播放——**观众开始排斥狗血撕闹**。面向中老年：不必追求「狠打脸」，可走「被轻视 → 被心疼 → 一个体面举动翻盘」

### B 组（都市情感）——3 条铁律
4. **身份/认知差 = 误会引擎**（比恶毒反派更安全好用）：双方信息不对称，每集产一个笑点或打脸点，不用撕逼也能推冲突
5. **先让弱者退场/错场/当众撕破，再由强者回头低头**：「不纠缠的女主 + 追悔的低姿态强者」是当下最稳爽点结构
6. **名场面 = 公开场合 + 一句话捅破窗户纸**：传播最强的桥段全是「当众信息炸弹」——设计脚本时先想「这句台词在什么公开场合、由谁当众说出、打谁的脸」

### C 组（通用打法）——官方课硬核清单
7. **打脸四部曲**（工业化模板）：铺垫（反派主动挑衅，越过分越好）→ 羞辱（主角隐忍憋大招）→ 反转（亮底牌，要「全场震惊」）→ 碾压（余震收尾，给爽感兜底）
8. **数字魔法**：具体数字 >> 抽象描述（「五招败了宗师」> 「轻松打败高手」）
9. **每 20-30 秒必须一个情绪节点**（台词冲突/动作冲突/隐藏信息曝光）
10. **开场五要素**：人设（用具体事件展示，不用旁白）+ 主线目标 + 困境代入 + 情绪推进 + 一句话干四件事
11. **金句库**：15 条来源原句 + 14 条填空模板（见分册 03 的 B3）——「桥段不怕老，怕的是表达旧」
12. **情绪才是核**（官方课原话）：「观众共情的从来不是『喝洗脚水』这个行为，而是『尊严被践踏』的情感带入——外在的羞辱只是载体」

## 三、写轻便侠脚本时的对照清单

- [ ] 开场（前 3 秒）：三型钩子选一（直接冲突 / 强悬念 / 极致反差），**开篇直接上高潮**
- [ ] 打脸结构完整（铺垫→羞辱→反转→碾压），羞辱用**具体一句话**，反转给**一个动作**
- [ ] 至少一处**数字碾压**（13.8公斤 / 一百公斤 / 一秒折叠 / 三十九公里）
- [ ] 15 秒内 2-3 个情绪节点（约每 4-6 秒一个信息翻转）
- [ ] 面向中老年走「**体面爽**」：斗嘴可以、撕逼不要；结尾给对手台阶（服气/竖拇指）反而更讨喜
- [ ] 金句收尾 + 品牌锚点；单句 8-12 字
- [ ] 与四池/已拍片查重（未入池的手动任务也算）

# 短剧结构知识库（爆款文案智能调用）

> 来源：2026-09-23 调研（听花岛方法论/红果编剧教程/虎嗅定焦拆解/数英黄金原则等）+ 本地化适配（12-16s 软广）
> 调用方式：`lib/copybook.py` 自动注入每次文案生成（adapt_lines / 脚本生成）

## 一、时间节拍（按秒拆解，短剧版适配到 12-16s）

| 时间 | 任务 | 我们视频的对应 |
|---|---|---|
| **前 3 秒** | 强情绪冲突 + 悬念：画面冲击 / 颠覆性台词 / 激烈动作。**不给观众思考时间** | 镜1：开场冲突钩子（质疑/拦阻/教训）|
| 前 10 秒 | 人物关系 + 冲突 + 悬念全交代（"3秒冲突+3秒转折+4秒悬念"）| 镜1-3：质疑升级 |
| 30 秒 | 核心爽点（逆袭/打脸/三连击）| 镜3-4：反转打脸 |
| 1-3 分钟 | 情绪闭环（低谷→转折→高潮）| 结尾：反差收尾 + 品牌锚点 |

**核心公式**：「3秒定生死 + 15秒抛钩子 + 25秒大反转 + 30秒促互动」→ 压缩版：**3秒钩子 → 中段质疑升级 → 结尾打脸反转**。

## 二、黄金结构（四阶）

1. **高能开场**（极端场景建立记忆点）——质疑、冲突、对抗，不铺垫
2. **反转强化**（身份/认知反转制造期待）——"原来这么轻/这么快/这么稳"
3. **矛盾升级**（新冲突点拉动留存）——质疑加深（"能行吗""真的假的"）
4. **终极引爆**（震撼设定引爆传播）——一句话打脸 + 品牌收尾

### 台词结构模板
- 同一句话多层反转（3轮递进质疑 → 1击反转收尾）
- **前置对比**：先立"旧/惨/难"，再爆"新/爽/易"（反差越大越好）

## 三、爽点类型库（情绪驱动）

| 类型 | 原理 | 我们的化用 |
|---|---|---|
| **打脸虐渣** | 被质疑→证据碾压（"用最少的字让人打脸"）| 大爷质疑重量 → 儿子单手拎起 |
| **身份/认知反转** | 扮猪吃老虎，伪装→暴露 | 旧车骑十年 → 一键折叠新体验 |
| **螺旋式上升** | 每次质疑都被更强证据打回 | 三连问 → 三连答 |
| **反差爆发** | 先"惨/低"再爆发 | 破旧轮椅 vs 折叠新品 |
| **数字碾压** | 具体数字制造说服力 | 十三点八公斤 / 一秒折叠 |
| **路人反应** | 他人惊叹=观众代入 | 路人瞪眼/竖拇指/摘墨镜 |

**爽点密度**：每集一个小爽点，3镜一个大爽点。**没有打脸，短剧必崩**。

## 四、狗血/土味要素（土狗爱看）

- **强冲突开场**：一上来就"吵"（质问/拦阻/嫌弃），不寒暄
- **关系张力**：母子对抗、邻里攀比、老同事惊讶——**熟人关系里的面子之争**最土最爽
- **土味金句**：直白、口语、带点狠劲（"轮不到你说扔就扔"）
- **夸张反应**：瞪眼、后退半步、摘墨镜、掏手机拍
- **捡漏感/炫耀感**：花小钱办大事、别人没有我有
- **反转密度**：每 3-4 秒一个信息翻转（远超长视频）

## 五、钩子与悬念

- **信息缺口**：说半句留半句（"你猜怎么着——"）
- **视觉悬念**：动作做到一半切走
- **结尾钩子**：评论引导（"你爸妈会选哪个？"）
- **蔡格尼克效应**：未完成事件记忆留存率 +67%

## 六、台词规则（字字千斤）

1. **长度**：每句 **8-12 字**最佳（朗读 2.5-3s），最长不超过 15 字
2. **风格**：大白话、零修饰、不加文学性；"用最少的字让人物打脸"
3. **金句化**：高光时刻一句顶十句
4. **禁止**：大段旁白、堆砌辞藻、解释性台词（节奏杀手）
5. **反重复铁律**："同一种桥段千万别反复用"——**与本项目创意去重机制一致**（lib/ideas.py）

## 七、魔性/洗脑结构

- **重复升级**：同一动作/句式重复 3 次，每次节奏/力度升级（咔哒节奏）
- **句式洗脑**：短句+相同结构+递进（"一键折叠。再试一次。还是这么顺。"）
- **声音钩子**：固定音效绑定固定动作（折叠咔哒声）
- **结尾收束**：重复句+品牌落地

## 八、检查清单（每篇文案必查）

- [ ] 前 3 秒有冲突/悬念钩子（不是平铺直叙）
- [ ] 每句台词 ≤12 字（超了拆）
- [ ] 至少 1 个打脸/反转点
- [ ] 质疑→打脸的结构完整（起-压-爆）
- [ ] 台词无文学腔、无解释性长句
- [ ] 无重复桥段（对照已用创意库）
- [ ] 结尾有反差收束+品牌锚点（不硬广）
- [ ] 抖音适配：垂直人群（中老年/孝心/助残）语言

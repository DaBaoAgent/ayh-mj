## 一、灵魂引擎：马甲梗（身份认知错位）

短剧的底层模型是**大型剧本杀**：
- **主角** = 唯一知道真相的玩家（我知道我很强，但我不说）
- **反派/配角** = 蒙在鼓里、不断作死的玩家（越作死越期待被打脸）
- **观众** = 上帝视角的旁观者（等着看底牌亮出的瞬间）

**三大心理爽点（每个剧本至少命中一个）**：
1. **扮猪吃老虎的掌控感**：「我很强，但我不说，看你们如何作死」
2. **期待逆袭的宣泄感**：前期被压抑得越狠，打脸时越爽——**憋屈与释放成正比**
3. **打破身份的幻想**：真有本事的人往往藏在最平凡的外表下

**铁律：身份前期越低微，后期打脸的爽感越强烈。**

马甲三种主流形态：
| 类型 | 设定 | 我们的对应（15秒软广） |
|------|------|----------------------|
| 王者低调型 | 大佬隐藏身份受辱→亮身份 | 老人被小看「啥也不会」→现场亮操作 |
| 大佬体验型 | 强者装弱者被欺负→翻盘 | 小巧被小看「能行吗」→真实力打脸 |
| **信息差博弈型** | 主角知道别人不知道的（重生/预知） | **我们知道车多强，质疑者不知道→作死→被打脸** ★最适配 |

## 二、开场：3 秒定生死

**钩子四型**（高频刺激，每 10-15 秒一个）：
- **画面钩**：反常识画面（车自己动了 / 单手拎起）
- **悬念钩**：说半句留半句（「你猜怎么着——」）
- **情绪钩**：冲突喊话（「你疯了吧？」/「我看悬！」）
- **转折钩**：预期被打破（以为学不会→车听懂了）

**开篇三板斧**（压缩版）：第1秒视觉冲击+情绪冲击 → 第2-3秒矛盾升级 → 第4秒小高潮+悬念

**禁忌**：❌ 日常流水账开场 ❌ 大段背景铺垫 ❌ 没有视觉冲击的纯对话

## 三、打脸结构（四步，缺一不可）

```
① 铺垫（立靶子）：对手亮出资本/身份，建立「他看不起主角」的合理性
② 羞辱（加压）：**当众**贬低/嘲讽/下注，越具体越狠越好（经济羞辱/能力羞辱/安全羞辱）
③ 反转（亮底牌）：主角一句话/一个动作完成翻盘——**动作要可视、要干脆**
④ 碾压（收爽点）：质疑者当场服气（认怂/呆住/竖拇指）+ 围观者反应 + 金句收束
```

**关键技法**：
- **赌约/加注**：让对手「下注」（「能行我请客」）——输了被兑现时爽感翻倍（短剧经典）
- **自我打脸**：让质疑者**亲自验证**（自己坐上去/自己试），打脸由行动完成
- **数字碾压**：具体数字完胜模糊形容词（「一百公斤」>「很结实」）
- **路人反应**：他人惊叹 = 观众代入（「哎哟喂」式惊叹词）

## 四、台词法则与金句模板

**黄金法则**（scriptify 过稿标准）：
1. 单行 ≤12 字（短剧节奏 = 一句一拳）；避免单词成行
2. **全口语**：诶/咋/啥/哟/哎哟喂/得嘞——严禁书面语（「对此」「然而」「倘若」）
3. **有潜台词**：说一半留一半，不解释、不铺垫
4. **人物有腔调**：每个人说话方式必须不同（嘴损的/淡定的/夸张的）

**高频名场面句式（可直接化用）**：
| 场景 | 台词模板 |
|------|---------|
| 认知质疑 | 「X 能 Y 吗？我看悬」 |
| 经济羞辱 | 「X 你也配？」「赔得起吗？」 |
| 安全羞辱 | 「别逞能，摔了别赖我」 |
| 下赌注 | 「你要能 X，我 Y」 |
| 反转预告 | 「你说呢？」「瞧好了」「你坐坐看」 |
| 惊叹反应 | 「哎哟喂，还真 X！」「好家伙！」 |
| 碾压收尾 | 「就这样，还 X？」 |
| 金句对仗 | 「X 归你，Y 归我」 |

**土味金句底层句式**：
- 「今天的我你爱答不理，明天的我你高攀不起」（翻身宣言）
- 「她本是 X，却伪装成 Y，直到他当着所有人的面叫了一声 Z」（身份反转）
- 「X 归你拎，我 Y 着走」（对仗式碾压）

## 五、剧本格式规范（AI 剧本通用）

```
第X集 / 场X-Y 地点 时间 内/外
人物：角色1 角色2

△（人物动作/场景描述——所有非对话内容）
角色1：对话内容
角色2：对话内容
角色1 os：内心想法（不出声）
VO（画外音）：电话/回忆里的声音
【闪回】…【闪出】
```

**要点**：场景标注完整、△统一标动作、对话不加引号、多用可执行的视觉动作、少抽象描写。

## 六、过稿 5 条件（自检清单）

- [ ] **开篇爆点**：第1秒有视觉+情感冲击（冲突场景：撞见/被陷害/被当众羞辱）
- [ ] **画面感**：❌「他很生气」→ ✅「攥紧拳头，指甲掐进掌心」
- [ ] **台词精简**：单行短句、口语化、有潜台词
- [ ] **节奏**：30 秒内必有吸引点；每集至少 1 个冲突/爽点；避免连续静态对话
- [ ] **前期集中**：核心矛盾尽早建立，最大冲突前置

## 七、压缩到 15 秒的转化原则（ayh-mj 实操）

15 秒 = 短剧的「一个呼吸」，只能装「一次完整的打脸」：

| 短剧（100集） | 15 秒软广 |
|--------------|----------|
| 身份马甲（隐藏真身份） | **信息差马甲**：观众+主角知道车强，质疑者不知道 |
| 前3集铺垫冲突 | 第1句词 = 冲突喊话（当众质疑/羞辱） |
| 每10集一个卡点 | 每 3-4 秒一个信息翻转（镜内两句来回） |
| 30秒大反转 | 第 8-11 秒 = 反转动作（可视、干脆） |
| 大结局打脸 | 第 12-15 秒 = 认怂 + 数字碾压 + 金句+品牌 |

**四镜打脸模板**：
- 镜1（0-4s）：**羞辱**——对手当众质疑/贬低（立靶子）
- 镜2（4-7.5s）：**加注**——羞辱升级 + 主角反将一句（悬念拉满）
- 镜3（7.5-11s）：**反转**——当场验证动作 + 质疑者吃惊（打脸）
- 镜4（11-14.5s）：**碾压**——数字/事实补刀 + 对手认怂 + 金句品牌

## 八、踩坑警示（血泪）

- **「看的时候很爽，看完很假」的病根**：只堆爽点、不顾逻辑 → 所有冲突必须符合人物关系与常识（熟人社会的面子之争最真实）
- **同一桥段不要重复用**（我们已有创意去重机制：模板/角度/卖点/角色四池轮换）
- **"抑"要抑在主角能力/认知上，不要抑产品质量**——软广先抑后扬，「抑」过头会伤品牌认知
- 我们的爽点上限：**质疑者亲自验证 + 当场服气**（15 秒最有效）

## 九、官方课增补（2026-09-25 从 21 部热剧档案提炼，详见 hot_dramas_2026.md）

**打脸四部曲（工业化模板，红果官方课口径）**：

| 步 | 名称 | 怎么写 | 要点 |
|----|------|--------|------|
| 1 | 铺垫（反派主动挑衅） | 抢你女人、毁你合约、当众羞辱——**越过分越好** | 挑衅要具体、当众、有身份落差 |
| 2 | 羞辱（主角隐忍） | 不是怂，是憋大招：微笑退让、不置可否 | 观众知道反转要来但不知道怎么来=期待感 |
| 3 | 反转（炸场） | 黑卡亮出、实力碾压、一招制敌 | 必须给够：**全场震惊、反派崩溃、吃瓜群众目瞪口呆** |
| 4 | 碾压（余震收尾） | 打完脸不是结束：道歉/后悔/排队求饶 | **给爽感兜底，确保读者有回甘** |

**四条加固规则**：
1. **羞辱只是载体，情绪才是核**——观众共情的从来不是行为本身，而是「尊严被践踏」。形式会过时，情绪不会
2. **反转必须「意料之外，情理之中」**——每次打脸都建立在前期埋的细节上
3. **数字魔法**：具体数字 >> 抽象描述（「五招败了宗师」＞「轻松打败高手」）
4. **困境三原则**：时长控制（困境不久留）→ 留希望（暗示有反击准备）→ 针对性（对手动机清晰）

**★ 面向中老年的「体面爽」（2026 趋势，正对轻便侠受众）**：
- 红果 45 岁以上用户已过半；《好雨知时节》「摊开证据、体面拆婚」30 亿播放、8 月断层第一
- 行业观察：观众开始排斥狗血撕闹，「普通人逆风翻盘的真实共情」正在替代「无脑开挂的虚假快感」
- 落地原则：**斗嘴可以、撕逼不要**；结尾给对手台阶（服气/竖拇指）反而更讨喜
- 我们的打脸力度基准：**被小看 → 当场验证 → 服气收**（不搞低俗羞辱、不伤品牌认知）

**名场面公式**：**公开场合 + 一句话捅破窗户纸**——写脚本先想「这句台词在什么公开场合、由谁当众说出、打谁的脸」，而不是加长铺垫

**节奏**：每 20-30 秒一个情绪节点（台词冲突/动作冲突/信息曝光）→ 15 秒版 = 每 4-6 秒一个信息翻转

**台词自检**：写完**大声朗读**，砍掉 1/3 再看核心信息还在不在
